# PA Performance Presentation (3D)

เว็บนำเสนอผลการปฏิบัติงานตามข้อตกลงในการพัฒนางาน (PA) ต่อคณะกรรมการประเมิน
แบบ **cinematic fullscreen 3D interactive presentation** — ไม่ใช่ระบบกรอกข้อมูล
ไม่ใช่ dashboard และไม่ใช่เว็บไซต์ให้ความรู้

สร้างด้วย React + TypeScript + Vite, ใช้ [react-three-fiber](https://r3f.docs.pmnd.rs/)
สำหรับฉากพื้นหลัง 3D และ [Framer Motion](https://motion.dev/) สำหรับทรานซิชันของสไลด์

## โครงสร้างเนื้อหา

สไลด์ถูกจัดตามโครงสร้าง PA:

- **ส่วนที่ 1** ข้อตกลงในการพัฒนางานตามมาตรฐานตำแหน่ง
  - การจัดการเรียนรู้
  - การส่งเสริมและสนับสนุนการจัดการเรียนรู้
  - การพัฒนาตนเองและวิชาชีพ
- **ส่วนที่ 2** ประเด็นท้าทายในการพัฒนาผลลัพธ์การเรียนรู้ของผู้เรียน
  - วิเคราะห์สภาพปัญหา
  - นวัตกรรม/วิธีดำเนินการ
  - ผลลัพธ์ที่คาดหวัง (เชิงปริมาณ/เชิงคุณภาพ)

## แก้ไขเนื้อหาให้เป็นของคุณ

เนื้อหาทั้งหมดอยู่ในไฟล์เดียว: [`src/content.ts`](src/content.ts) — แก้ไขข้อความ
ในอาร์เรย์ `slides` ให้ตรงกับข้อมูลจริงของครูแต่ละท่านก่อนนำเสนอ (ชื่อ-สกุล,
โรงเรียน, รายละเอียดผลงาน, ผลลัพธ์ ฯลฯ) ไม่ต้องแก้โค้ดส่วนอื่น

## การใช้งาน / นำเสนอ

- **เลื่อนสไลด์**: ลูกศรขึ้น/ลง/ซ้าย/ขวา, Page Up/Down, เว้นวรรค, เลื่อนล้อเมาส์
  หรือปัดจอสัมผัส
- **ไปสไลด์แรก/สุดท้าย**: Home / End
- **จุดไข่ปลาด้านล่าง**: คลิกเพื่อกระโดดไปยังสไลด์ที่ต้องการ
- **ปุ่มมุมขวาบน**: สลับโหมดเต็มจอ (แนะนำให้ใช้ขณะนำเสนอจริง)
